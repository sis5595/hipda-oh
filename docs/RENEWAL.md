# 证书续期与常见问题

[返回首页](../README.md) · [首次安装](INSTALL.md) · [日常升级](UPDATE.md)

侧载应用有使用期限。可以把证书理解为签名身份，把设备授权理解为“这台手机可以运行到什么时候”。两者期限可能不同，**以安装工具中这份应用的实际到期日为准**。

不要为了续期卸载 HiPDA·OH，不要清空应用数据，不要在原因不明时重置或删除证书。论坛上的帖子仍在，不代表本机账号会话、设置和阅读记录可以恢复。

## 到期前如何准备

1. 打开最初安装 HiPDA·OH 的小白助手，检查当前华为账号仍是原账号。
2. 进入工具提供的应用/安装记录或续期页面，核对目标是 **HiPDA·OH / `com.sis5595.hipdaoh`**，查看显示的到期日期。
3. 小白 3.1 [发布说明](https://github.com/likuai2010/auto-installer/releases/tag/3.1.0)列出一键续期及添加日历提醒。**只有你的界面确实提供这些入口时才使用**；日历权限由你决定，也可自行在日历记一个提前一周的提醒。
4. 保留原工具和它的本地签名/备份文件。3.1 会在“下载/小白调试助手”保存账号和备份，别把它们当普通下载垃圾清理，也不要发给别人。

**目前尚未亲自核对 3.1 续期页面的按钮位置和完整结果，不能给出假定的逐按钮截图教程。** 若找不到自身续期入口，可先从电脑沿用原签名再次签装；不要卸载手机助手来“重装试试”。上游已有[找不到自身续期按钮的反馈](https://github.com/likuai2010/auto-installer/issues/124)，不是你一定操作错了。

## 已到期但尚未卸载

保持应用原样。用原安装工具、原账号和原签名材料重新签名有效 HAP，再尝试覆盖安装；如果工具报签名冲突就停止。完成后按[升级后的四项检查](UPDATE.md#每次升级后都做这四项检查)核对数据。

续期应更新有效授权，而不是无条件更换签名身份。本项目尚未完成 3.1 续期数据保留的真机验收，不能承诺任何“重签一次必定无损”。

## 签名不一致或证书失效怎么办

1. **停止，不卸载。** 保存错误码和版本信息，截图遮住账号、设备标识、私信和凭证。
2. 确认是否换过电脑、华为账号、安装器，或点过“重置证书”。同一华为账号也可能产生不同密钥。
3. 回到原工具，确认原签名材料/受保护的本地备份仍在。按原工具的恢复说明处理，不把私钥上传给网站或维护者。
4. 若只需更新授权且仍可沿用原签名，再尝试覆盖；无法确认时请先向安装工具作者咨询。
5. **原签名身份已丢失时，本项目没有经过验证的无损恢复方案。** 暂留旧应用与本地数据，等待明确方案。不要用卸载来掩盖问题。

## 常见问题

| 看到什么 | 先怎么做 | 成功标志 / 何时停止 |
|---|---|---|
| 华为登录失败、授权回不来 | 在华为官方网页确认账号可登录、开发者认证完成；回小白重试授权 | 工具显示原账号已登录；验证码自己填写 |
| 手机只充电、设备不在线 | 换可传数据的线或 USB 接口；手机解锁、检查 USB 调试和授权弹窗 | 工具能识别自己的设备 |
| 无线连接失败 | 两端同一可信 Wi-Fi；重新读手机当前 IP 和端口，再点连接设备 | 设备在线；不要照抄示例地址或开公网端口 |
| 签名失败 / 50424 / p12 报错 | 记录完整错误码，核对工具版本、账号和包名，查工具 Issues | 未确认原因不重置证书；不上传 p12 或密码 |
| “当前证书不存在”，但证书列表中有证书 | 先检查工具是否沿用该证书对应的原私钥和 CSR；仅下载证书不能补回私钥 | 本轮通过核对三者匹配、恢复原签名配置后成功安装手机助手；不随便选另一张证书 |
| 版本不兼容 | 检查手机是原生 HarmonyOS 6.1.1 或更高，且包不是 Android APK | 系统不满足时先停止，不装修改权限的包 |
| 安装失败、版本过低 | 核对目标版本与已安装版本；使用正式发布的较新 HAP | 不降级、不先卸载 |
| 下载完成但校验失败 | 在 HiPDA·OH 重新下载；重复失败反馈版本和文件名 | 只有 SHA-256 通过才可交接 |
| 系统分享里没有小白 | 用更新页的“用小白助手打开”，或分享“另存为”后在小白“选择”中找文件；仍不行回电脑安装 | 小白识别正确版本；不把工具打开当成已安装 |
| 小白显示本机未连接 | 回首页“更换地址”重新连接；仍失败时按首次安装教程在电脑“一键同步”，处理手机信任提示 | 设备检查通过；连接问题不靠重置证书解决 |
| 小白选择 HAP 报 RangeError | 保留 HAP 和错误信息，查看[上游反馈](https://github.com/likuai2010/auto-installer/issues/116)；优先尝试原电脑工具 | 不通过卸载旧 HiPDA·OH 解决选包异常 |
| 更新后退出了论坛账号 | 先看账号管理和设置/历史是否仍在；会话可能自然到期 | 重新登录后核对其他数据，不清空应用 |

## GitHub 打不开或下载中断

1. 等网络恢复后重试，或换自己的 Wi-Fi/移动网络。
2. 手机不通时，在电脑浏览器打开[官方 Releases](https://github.com/sis5595/hipda-oh/releases)，展开 **Assets** 下载 HAP。
3. 若提示访问次数限制，稍后再试，不要不断刷新；网页下载入口仍可尝试。
4. 不使用来源不明的 GitHub 镜像，不把 GitHub Token 填入 HiPDA·OH，它不需要登录 GitHub。

## HoKit 能否备用？

HoKit 作者提供[桌面版](https://github.com/yabi-zzh/HoKit)和[手机版入口](https://gitcode.com/yabi-zzh/HoKit-App)；作者自己的[聚映项目](https://github.com/yabi-zzh/livify-ohos)也推荐这两个入口。小白 Issue #116 有用户反馈换 HoKit 后成功选包。

这仅说明它值得作为备选测试，**不证明它能继承你的小白签名**。目前没有完成 HiPDA·OH 的 HoKit 手机交接、跨工具签名及数据保留实测，不建议普通用户直接换工具覆盖日常应用。也不要混淆桌面 HoKit 的手机投屏服务组件与完整手机签装工具。

需要求助时，只提供工具版本、系统版本、HiPDA·OH 版本及遮挡后的错误截图；不要提供密码、验证码、证书私钥、账号缓存或论坛 Cookie。
