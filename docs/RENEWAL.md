# 证书续期、迁移与常见问题

[返回首页](../README.md) · [首次安装](INSTALL.md) · [日常升级](UPDATE.md)

侧载应用有使用期限。证书代表签名身份，设备授权决定应用能在哪台设备运行及期限；两者可能不同，以所选工具和应用实际显示为准。

**项目已停止推荐小白调试助手，不再维护其专属交接、缓存、历史及续期兼容。安装器选型正在重新验证，目前没有默认替代工具。** HoKit、QSStore 等方案尚未完成本项目的迁移、覆盖安装和续期验收。

## 原小白用户迁移提醒

- 建议以后改用经项目验证的新安装工具，具体工具及步骤将在实测后公布。
- 换工具可能无法继承原来的签名身份；即便使用同一个华为账号，也不一定能覆盖安装。
- 如果无法覆盖，可能需要由你主动接受重新安装的成本，并重新登录论坛账号。
- 论坛服务器上的帖子、回复等数据不受重新安装客户端的影响；客户端本地设置、会话和阅读记录可能丢失。目前没有已验证的跨工具本地数据迁移保证。
- 迁移前记录自己需要的设置和阅读位置，确认能重新登录；不要公开账号缓存、证书、私钥、密码或验证码。
- **HiPDA·OH 不会为了迁移自动卸载应用或清除数据。** 如果你不接受本地数据丢失，可先保留现有应用，等待新方案验收。

## 到期前准备

1. 查看当前应用和授权的实际到期日，自行设置提醒。
2. 保留当前签名材料的受保护备份，不把它们作为下载垃圾清理，也不要发给别人。
3. 关注项目的安装器验证进展，按经验证工具的官方说明处理授权刷新或续期。
4. 续期前确认工具是沿用原签名覆盖，还是会创建新的签名身份；无法确认时先停止。

本项目不管理用户证书或私钥，不代替用户续期，也不保证任意工具“重签一次必定无损”。当前不提供小白缓存修复或续期操作教程。

## 已到期或签名不一致

先保留现有应用，保存错误码、目标版本和原工具信息。不要由程序自动卸载来绕过冲突。

如果新工具经验证能够沿用原签名，可按其说明尝试覆盖，再按[升级后核对](UPDATE.md#升级后核对)检查版本与本地数据。如果签名无法继承，则按上面的迁移提醒决定是否接受重新安装；不能承诺原签名丢失后仍可无损恢复。

## 常见问题

| 看到什么 | 怎么处理 |
|---|---|
| 不知道用什么安装工具 | 安装器正在重新验证。新手建议等待已验收教程，不把候选工具当默认可靠方案 |
| 华为登录、认证或授权失败 | 在华为官方页面核对自己的账号状态，再按所选工具官方说明处理；验证码自己填写 |
| 手机只充电、设备离线 | 检查数据线、手机解锁及调试授权；连接失败不靠更换证书解决 |
| 签名失败 | 记录完整错误码，核对工具版本、包名和原签名身份；不要随意重置证书 |
| 工具要求先卸载 | 先停止，阅读迁移提醒；是否接受重新安装和本地数据丢失由你决定 |
| 系统版本不兼容 | 确认原生 HarmonyOS 6.1.1 或更高，且下载的是 HAP，不是 Android APK |
| 下载完成但校验失败 | 点击“下载更新包”重试；反复失败时反馈版本与文件名，不分享、保存或安装损坏文件 |
| 系统分享没有合适工具 | 关闭面板，点击“保存安装包”，再由工具手动导入；也可从官方下载页面取得文件 |
| 保存失败或取消 | 重新选保存位置，检查空间；不要导入失败操作留下的不完整文件 |
| 更新后需要登录论坛 | 检查是否主动重新安装或论坛会话到期，再登录；核对本地设置和阅读记录 |

## GitHub 打不开或下载中断

1. 等网络恢复后重试，或使用自己的其他可信网络。
2. 手机不通时，用电脑浏览器打开[官方 Releases](https://github.com/sis5595/hipda-oh/releases)，展开 **Assets** 下载 HAP。
3. 提示访问次数限制时稍后重试，不不断刷新。
4. 不使用来源不明的下载镜像，不向客户端提供 GitHub Token。

求助时只提供工具版本、手机系统、HiPDA·OH 版本及遮挡个人信息后的报错。不要提供密码、验证码、证书私钥、账号缓存或论坛 Cookie。
