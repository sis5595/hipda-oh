# HiPDA·OH

一个原生鸿蒙版的 **4D4Y 非官方客户端**，希望把 HiPDA·NG 熟悉、顺手的论坛体验带到鸿蒙手机上。

本项目以 NG 为主要参考，尽量对齐它的界面布局、操作习惯和日常功能，并结合鸿蒙系统做适当调整。它由社区爱好者维护，与 4D4Y 官方没有隶属关系。

## 下载

当前版本：**1.0.0-beta.5**。

本次更新：

- 修复从用户详情页搜索帖子时，结果混入其他作者主题的问题。
- 修复信息提醒更新后，仍跳到旧回复位置的问题。
- 从提醒进入已关注主题时，在目标楼层增加“取消关注此主题”按钮。

从 [GitHub Releases](https://github.com/sis5595/hipda-oh/releases/tag/v1.0.0-beta.5) 下载 `hipda-oh-1.0.0-beta.5-unsigned.hap`，源码 ZIP 不能直接安装。历次更新见[更新记录](CHANGELOG.md)。

**目前未上架应用商店，通过 GitHub 下载后侧载安装。** 安装需要你自己的华为开发者账号和安装工具，不是点击 HAP 就能安装。

当前构建面向 HarmonyOS 6.1.1 及以上的原生鸿蒙设备，不适用于 Android。

## 如何安装

- **第一次使用：**[首次安装教程](docs/INSTALL.md)
- **已经装过：**[日常升级教程](docs/UPDATE.md)
- **到期或遇到错误：**[证书续期与常见问题](docs/RENEWAL.md)

1. 从 [Releases](https://github.com/sis5595/hipda-oh/releases) 下载 Beta 的 `.hap` 附件（不是源码 ZIP）。
2. 使用支持 HarmonyOS NEXT 的安装工具，为自己的设备完成签名和安装。**安装工具正在重新验证，目前没有默认推荐工具。**

这里提供的是未签名 HAP，不能点击文件直接安装。侧载可能需要华为开发者账号、开启开发者模式、连接或绑定设备，以及在签名到期后续签。具体条件以所选工具和系统提示为准；尚未验收的工具不代表可靠的默认方案。

项目已停止推荐小白调试助手，原小白用户建议今后迁移到经项目验证的新工具。换工具可能无法继承原签名，不能覆盖时可能需要主动重新安装并登录论坛；论坛服务器上的帖子等数据不受影响，但本机会话、设置和阅读记录可能丢失。请先阅读[迁移说明](docs/RENEWAL.md#原小白用户迁移提醒)，应用不会自动卸载旧版。

## 可以做什么

- 浏览版面和帖子，下拉刷新、滚动加载，调整排序和置顶帖显示。
- 阅读引用并跳转楼层，查看原图、缩放和切换多图，保存或分享图片，下载附件。
- 发主题、快速回复、引用回复、上传多图，以及编辑或删除自己的帖子。
- 搜索标题、全文和作者，查看自己的主题与回复，管理收藏、关注和黑名单。
- 收发私信、查看帖子提醒，切换多个账号，调整主题、字号和行距。
- 设置发帖小尾巴，在“关于”中查看版本和项目链接。

各项操作仍受论坛规则和账号权限限制。消息提醒显示在应用内，目前不提供后台系统推送。

## 隐私与反馈

应用没有广告和统计 SDK，不读取或保存论坛密码。已保存账号的会话由鸿蒙系统安全存储保护；具体说明见[隐私政策](docs/PRIVACY_POLICY.md)。

遇到问题可在 [Issues](https://github.com/sis5595/hipda-oh/issues) 中反馈，说明操作步骤、手机型号和系统版本。截图前请遮住私信、账号等个人信息。联系邮箱：sis5595@gmail.com。
