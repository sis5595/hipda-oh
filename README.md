# HiPDA·OH

一个原生鸿蒙版的 **4D4Y 非官方客户端**，希望把 HiPDA·NG 熟悉、顺手的论坛体验带到鸿蒙手机上。

本项目以 NG 为主要参考，尽量对齐它的界面布局、操作习惯和日常功能，并结合鸿蒙系统做适当调整。它由社区爱好者维护，与 4D4Y 官方没有隶属关系。

## 下载

当前版本：**1.0.0-beta.3**。

本次更新：

- 新增“关于”页面，可查看安装版本和联系方式。
- 新增“小尾巴”，可在设置中开启，并修改文字和链接。
- 修复部分情况下自己的回帖没有“编辑”选项的问题。
- 扩大帖子编辑框，键盘打开时也能看到发送按钮。

从 [GitHub Releases](https://github.com/sis5595/hipda-oh/releases/tag/v1.0.0-beta.3) 下载 `hipda-oh-1.0.0-beta.3-unsigned.hap`，源码 ZIP 不能直接安装。历次更新见[更新记录](CHANGELOG.md)。

**目前尚未上架应用商店，现阶段只能侧载。** 项目正在积极准备上架境外华为 AppGallery，希望未来可通过海外商店正常下载安装和更新，但不承诺具体日期。

当前构建面向 HarmonyOS 6.1.1 及以上的原生鸿蒙设备，不适用于 Android。

## 如何安装

1. 从 [Releases](https://github.com/sis5595/hipda-oh/releases) 下载 Beta 的 `.hap` 附件（不是源码 ZIP）。
2. 使用[小白调试助手（Auto-installer）](https://github.com/likuai2010/auto-installer)，按工具提示为自己的设备完成签名和安装。

HAP 需要先用小白调试助手签名，不能点击文件直接安装。侧载可能需要华为开发者账号、开启开发者模式、连接或绑定设备，以及在签名到期后续签。具体条件以工具和系统提示为准。

更新时尽量沿用相同签名；若提示签名不一致，不要直接卸载，以免丢失本地账号会话和设置。

## 可以做什么

- 浏览版面和帖子，下拉刷新、滚动加载，调整排序和置顶帖显示。
- 阅读引用并跳转楼层，查看原图、缩放和切换多图，保存或分享图片，下载附件。
- 发主题、快速回复、引用回复、上传多图，以及编辑或删除自己的帖子。
- 搜索标题、全文和作者，查看自己的主题与回复，管理收藏、关注和黑名单。
- 收发私信、查看帖子提醒，切换多个账号，调整主题、字号和行距。
- 设置发帖小尾巴，在“关于”中查看版本和项目链接。

各项操作仍受论坛规则和账号权限限制。消息提醒显示在应用内，目前不提供后台系统推送。

## 隐私与反馈

应用没有广告和统计 SDK，不读取或保存论坛密码。已保存账号的会话由鸿蒙系统安全存储保护；具体说明见[隐私政策](docs/PRIVACY_POLICY.md)。

遇到问题可在 [Issues](https://github.com/sis5595/hipda-oh/issues) 中反馈，说明操作步骤、手机型号和系统版本。截图前请遮住私信、账号等个人信息。联系邮箱：sis5595@gmail.com。
